# Usability Validation Checklist: Plant Search Discoverability (SC-005)

**Feature**: UI Consolidation and User Experience Modernization  
**Success Criterion**: SC-005 — Users can identify where to perform plant lookup from navigation labels within 5 seconds on first visit.

## Validation Protocol

- Use first-time participants with no prior walkthrough of the current build.
- Start each participant on the unified landing page (`/`).
- Do not provide hints or explain navigation labels.
- Prompt: **"Where would you go to search for plants?"**
- Start timer when prompt is finished.
- Stop timer when participant points to or clicks the **Plant Search** navigation label.

## Pass/Fail Criteria

- **Pass (per participant)**: Identifies `Plant Search` in **<= 5.0 seconds**.
- **Fail (per participant)**: Takes **> 5.0 seconds**, selects wrong menu first, or asks for help.
- **Feature-level pass**: At least **90% of participants** pass the per-participant criterion.

## Execution Checklist

- [ ] Confirm target build includes updated navigation labels and titles.
- [ ] Record participant count and first-visit status.
- [ ] Run timed discoverability prompt for each participant.
- [ ] Capture observed time (seconds) and outcome (Pass/Fail).
- [ ] Calculate pass percentage and compare to feature-level threshold.
- [ ] Document remediation actions if threshold is not met.
